Built for one research group

One person installs BenchVault on a computer in the lab. Everyone else opens a link in their browser — nothing to install, nothing to configure, and no accounts on somebody else's servers.

Two roles keep it simple. Master users manage everything and create the accounts; Regular users work with their own records while seeing the lab's shared data. The first account created becomes the lab's Master.

In the app

Everything a lab actually tracks

Experiments

Procedures, parameters, and reactants pulled straight from your inventory — with a built-in calculator that works out masses, volumes, and stock-solution pipetting from a target molarity. Tag them, attach files, and export to PDF.

Inventory

Chemical stock with low-stock alerts and Excel import and export. When a reactant goes into an experiment, its quantity comes out of stock automatically, so the numbers stay honest without anyone remembering to update them.

Samples

Every sample stays linked to the experiment that produced it, and holds its own analyses and data files — NMR, HPLC, MS, whatever your lab runs. Print a QR code and the sample scans back to its record.

Equipment

Book instruments on a weekly calendar. Double-bookings are rejected as you make them, not discovered the morning of, and confirmations go out by email.

Graph

See how the work connects: which experiments produced which samples, which analyses came off them, and which chemicals they share. The questions that are tedious in a spreadsheet are a glance here.

And the rest of the day-to-day

Email alerts Reservation confirmations, low-stock warnings, and an optional weekly summary.
Cloud backup Scheduled backups to Koofr, Nextcloud, pCloud, Box, or any WebDAV server.
PDF & Excel export Export one experiment or a batch, with formatting intact.
Roles & permissions Master and Regular users, with ownership enforced on every record.

Running in ten minutes

No database to set up, no Python to install, no configuration files to learn.

  1. 1

    Install Docker

    Docker Desktop on Windows or macOS, Docker Engine plus the Compose plugin on Linux. It runs pre-packaged containers, which is why BenchVault brings its own database and needs nothing else from you.

  2. 2

    Set a password

    Copy .env.example to .env and change POSTGRES_PASSWORD. Nobody ever types this password — it is only how BenchVault's own pieces talk to each other. Just don't leave it as change-me.

  3. 3

    Start it

    Run docker compose up -d and open the address it prints. Create the first account, and that account becomes your lab's Master.

Claim the first account immediately. Until someone does, registration is open and anyone who can reach the address can take the Master account. Create it before sharing the link.

The Install Guide covers this properly — letting other computers reach it, setting up a domain with HTTPS, and what to do when something goes wrong.

What you need

Requirements

  • One computer that stays switched on (Windows, macOS, or Linux)
  • Docker
  • 4 GB RAM, 8 GB comfortable
  • A web browser for everyone else

PostgreSQL, Python, and Node all ship inside BenchVault's containers. You never install or configure any of them.

Stack

  • React 18 + TypeScript + Mantine v7
  • FastAPI (Python)
  • PostgreSQL 16
  • Caddy — automatic HTTPS
  • Docker Compose
  • JWT authentication
  • AGPL-3.0-only
